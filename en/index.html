Your script on real pages

On the left, the scenes with their page and who speaks in them. On the right, the page in Courier 12, with a 1.5 inch left margin and 1 inch on the other sides. See the shortcuts

Script formatting that happens as you type. Owlio handles the margins and the names.

Picks the next element

Enter after a character name starts the dialogue. Tab on an empty action line turns it into a character.

Completes names and places

Suggests the characters who speak most, places you already used and extensions like (V.O.). Accept with Tab.

Puts 2 lines side by side

When two characters talk at once, Ctrl+Shift+D sets dual dialogue on the page.

Writes in English or Portuguese

DAY, NIGHT and CUT TO: or DIA, NOITE and CORTA PARA:, chosen apart from the interface language.

The script from above

Cards, map, board and characters read the same script and change with it.

Each scene becomes a card with its place, a colour for the time of day, the page and who speaks. Drag a card and the whole scene moves in the script.

Drag from one avatar to another to link two characters. Family, love, conflict or work, each with its colour and a label of your own.

The Beat Board is an endless board for ideas: cards with colour and pictures, flow lines and as much zoom as you like.

Build a pixel-art avatar for each character: body, skin, hair, clothes and background, with a Random button.

Versions: go back to any copy of your script

Copies stack from newest to oldest. Drag the timeline, pick one and click Restore. Ctrl+Z undoes it.

  • Saves on its own every 5 minutes
  • A recovery copy every 20 seconds
  • Up to 30 dated copies per script

The app on Windows and Linux

The installer sets Owlio up for your user only, without asking for an administrator, and can open .fountain and .fdx files.

It is not signed yet. If Windows shows "Unknown publisher", click More info and then Run anyway.

See every release on GitHub
Linux, with Qt 6 and CMake
# dependencies (Ubuntu)
sudo apt install cmake g++ qt6-base-dev qt6-svg-dev libxcb-cursor0

# get the code
git clone https://github.com/berdfandrade/owlio
cd owlio

# build
cmake -S . -B build
cmake --build build -j

# run
./build/owlio

Questions about the app

What screenwriters ask before they download.

Ask a question on GitHub

Do I need Final Draft?

No. Owlio opens and saves .fdx files, but its main format is Fountain, plain text that other apps read too.

Does the PDF look like the screen?

Yes. The screen and the PDF use the same page drawing.

Does it work in Portuguese?

Yes. The interface and the script conventions (DIA, NOITE, CORTA PARA:, (MAIS), (CONT.)) can be in Portuguese.

What if the app closes suddenly?

It keeps a recovery copy every 20 seconds and offers your changes back when you open it again.

Is there a Mac version?

Not yet. For now, Windows with an installer and Linux by building the code.

What page size does it use?

US Letter, the standard for American scripts. A4 pages are planned.
